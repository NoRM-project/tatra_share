API:

GET /api/users
Response
[
    {
        id: 1
        full_name: "Name Surname",
        iban: "SK 1234 1234 1234 1234"
    }
]

POST /api/users
Payload
{
    full_name: "Name Surname",
    iban: "SK 1234 1234 1234 1234"
}
Response:
{
    id: 1
    full_name: "Name Surname",
    iban: "SK 1234 1234 1234 1234"
}

GET /api/groups
Response:
[
    {
        id: 1,
        name: "My group",
        members_count: 67
        user_balance: -10.00,
    }, ...
]

POST /api/groups
Payload
{
    name: "My group",
    member_ids: [1, 2, 3],
}
Response:
{
    id: 1,
    name: "My group",
    members_count: 67
    user_balance: -10.00,
}

    {
        id: 1,
        full_name: "Name Surname",
        iban: "SK 1234 1234 1234 1234",
    }, ...
]

POST /api/groups/{group-id}/members
Payload:
{
    full_name: "Name Surname",
    iban: "SK 1234 1234 1234 1234"
}
Response:
{
    id: 1,
    full_name: "Name Surname",
    iban: "SK 1234 1234 1234 1234",
}

Errors:
- If no user exists with the given `iban`, or if `full_name` does not match that user -> error "User not found".

Note:
- Group membership operations are performed as the current (simulated authenticated) user.
